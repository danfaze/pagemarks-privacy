🎡 PageWheel Test Page

Test your PageWheel extension installation and features

1. Quick Test

Press Ctrl+Shift+W (or ⌘+Shift+W on Mac) to open the PageWheel overlay.
You should see a 3D Rolodex appear with this tab as one of the cards.

2. Navigation Test

Once the overlay is open, use these controls:
  • ✓ ↑ or ↓ - Navigate between cards
  • ✓ Mouse wheel up/down - Navigate between cards
  • ✓ Enter or Space - Switch to focused tab
  • ✓ Esc - Close overlay

3. Mark & Tile Test

Press Ctrl+Shift+M (or ⌘+Shift+M) to mark this tab.
Open the test links below in new tabs, mark a few more, then right-click and select "Tile 2 Marked Tabs" or "Tile 4 Marked Tabs".
Test Page 1 Test Page 2 Test Page 3 Test Page 4

4. Settings Test

Click the PageWheel icon in your toolbar, then click "⚙️ Settings".
Try adjusting the animation speed, rotation angles, or other settings.
Changes apply immediately - reopen the overlay to see the effect.

5. Visual Check

Expected behavior:
  • ✓ Front card shows live thumbnail with clear text
  • ✓ Behind front card, you see header "slivers" of other tabs
  • ✓ Cards rotate smoothly in 3D (no jitter)
  • ✓ Blue background blur appears only during rotation
  • ✓ Background becomes transparent when rotation stops
  • ✓ Close button (×) is visible in top-right
✨ If all tests pass, PageWheel is working correctly!
