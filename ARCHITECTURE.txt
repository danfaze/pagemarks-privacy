KEY COMPONENTS:

1. BACKGROUND SERVICE WORKER (background.js)
   • Message bus with 8 operations
   • Tab querying and security filtering
   • Thumbnail capture with focus restoration
   • Marked tabs storage (chrome.storage.local)
   • Window tiling (2-up, 4-up layouts)
   • Settings management (chrome.storage.sync)
   • Command handlers (Ctrl+Shift+W, Ctrl+Shift+M)
   • Context menu items

2. CONTENT OVERLAY (content.js + content.css)
   • Shadow DOM for style isolation
   • 3D card stack with rotateX() transforms
   • Capture-phase event listeners
   • Lazy thumbnail loading
   • Scrim state machine (visible during rotation)
   • Z-ordering with isolation:isolate
   • AbortController cleanup

3. POPUP (popup.html/js/css)
   • Quick toggle button
   • Mark tab button
   • Settings link
   • Keyboard shortcuts display

4. OPTIONS PAGE (options.html/js/css)
   • 25+ settings across 6 categories
   • Live value display on sliders
   • Auto-save to chrome.storage.sync
   • Reset to defaults
   • Toast notifications

═══════════════════════════════════════════════════════════════════════════

DATA FLOW:

User Action → Command/Click → Background Worker → Message Bus
                                      ↓
                    Inject Script → Content Overlay → DOM Manipulation
                                      ↓
                              Update UI → User Sees Result

Settings Flow:
Options Page → chrome.storage.sync → Background Cache → Content Overlay

Thumbnail Flow:
Content Request → Background → captureVisibleTab → Focus Restore → Return Data
